# ULTRON repository operating rules

## Core workflow
Use the Superpowers method as a working discipline, not as a claim of affiliation:
1. Inspect the current implementation and the actual requested outcome before editing.
2. Write a concise implementation plan for multi-file work.
3. Keep changes small enough to verify; use tests or static checks where practical.
4. Implement the complete user-facing path, not just the visual shell.
5. Review the diff, responsive behavior, accessibility, and product truthfulness.
6. Run checks and inspect deployment status before saying a task is complete.

## Non-negotiables
- Ultron should reason and challenge claims constructively, not blindly obey or act theatrically hostile.
- Never claim live AI, memory, tools, user counts, benchmarks, or real neural activity unless implemented and verified.
- Keep the static site dependency-light and content readable without JavaScript.
- Respect keyboard use, touch, zoom, and prefers-reduced-motion.
- Treat a commit, a successful deployment, and a live visual inspection as separate evidence.
