# Project instructions

Before changing the site, read the relevant project-local skills in .agents/skills/. For a full redesign, apply these in sequence:

1. ultron-experience-design/SKILL.md — art direction and brand behavior.
2. frontend-architecture/SKILL.md — structure, semantics, resilient vanilla JavaScript.
3. interaction-motion/SKILL.md — purposeful motion and reduced-motion behavior.
4. accessibility-performance/SKILL.md — keyboard, contrast, responsive layout, and rendering budget.
5. truthful-product-content/SKILL.md — honest capability claims and meaningful copy.
6. superpower-workflow/SKILL.md — plan, implement, inspect, verify, and report evidence.

## Non-negotiables
- Keep Ultron's voice candid, ambitious, and evidence-seeking—not blindly obedient or theatrically hostile.
- Do not claim live AI, memory, external actions, benchmarks, users, testimonials, integrations, or real neural activity unless implemented and verified.
- Prefer dependency-free HTML/CSS/JS unless a concrete need justifies a library.
- Keep a useful static page if JavaScript or canvas fails.
- Respect keyboard navigation, touch, zoom, and prefers-reduced-motion.
- Commit related changes together, re-read committed files, check workflow status, and distinguish code commit from live deployment verification.
