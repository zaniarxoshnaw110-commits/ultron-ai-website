# ULTRON Design System — Concept 002

## Tokens
- Canvas: #07090d
- Panel: #0d1118
- Primary text: #f2f4f7
- Secondary text: #8b94a4
- Signal: #a2f770
- Depth: #8298ff, used sparingly with #a991ff
- Dividers: translucent cool-white lines

## Type
- Space Grotesk: display, headlines, and product labels.
- Manrope: readable paragraphs and body copy.
- DM Mono: coordinates, statuses, and system metadata.

## Interaction rules
- Lime indicates a selected state, action, or active signal—not a background fill for every component.
- Buttons visibly respond to hover and keyboard focus.
- Scenario selection uses both a visual treatment and aria-pressed.
- The demo uses fixed examples, local text processing, and explicit no-backend disclosures.
- Motion is optional and respects prefers-reduced-motion.

## Responsive behavior
- Desktop uses editorial split layouts and horizontal system flows.
- Tablet reduces flow columns and narrows supporting copy.
- Mobile prioritizes the headline, stacks hero content, turns scenario choices into a two-column grid, and preserves legibility for diagrams and console controls.
