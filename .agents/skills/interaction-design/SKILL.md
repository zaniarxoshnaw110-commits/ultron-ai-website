# Interaction Design
- Every control needs a purpose, accessible name, visible state, and implemented action.
- Use links for navigation and buttons for actions; expose menu and selection state with ARIA.
- Provide useful empty-input feedback and keep status feedback close to the control.
- Keep input processing local unless a real, disclosed service is connected.
- Never imply an AI model ran or an external action occurred unless it did.
- Verify mouse, keyboard, touch, and reduced-motion paths.
