# Truthful Product Content

- Explain the product thesis in concrete language before using abstract brand slogans.
- Separate a concept, prototype, implemented capability, and independently verified result.
- Do not invent customer numbers, testimonials, benchmarks, security certifications, integrations, model intelligence, memory, or tool actions.
- State clearly when an interactive console uses preset examples rather than a live model.
- Never call a decorative visualization a neural network, brain scan, or live reasoning trace.
- Be direct about uncertainty. If a claim cannot be verified, qualify it or omit it.
- CTAs should accurately describe what the destination does; no fake signup, waitlist, or broken submission form.
