# Frontend Design
- Start from the user's product thesis and choose an art direction with a recognizable point of view before writing CSS.
- Avoid generic AI gradients, repeated rounded cards, overused glassmorphism, gratuitous neon, and decorative dashboard chrome.
- Use typography, spatial rhythm, contrast, composition, and one memorable visual anchor to create identity.
- Keep a small, coherent token system and use accent colors with meaning.
- Make every section contribute a different part of the narrative; don't repeat the hero in different words.
- Design mobile intentionally instead of merely shrinking desktop.
- Include hover, active, focus-visible, empty, and selected states for all interactive controls.
- Keep the product capability boundary explicit; beautiful UI must not imply nonexistent functionality.
- Inspiration is a quality bar, not permission to copy another site's distinctive assets or text.
