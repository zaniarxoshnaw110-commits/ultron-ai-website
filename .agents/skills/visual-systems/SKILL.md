# Visual Systems
- Centralize color, type, spacing, borders, and motion decisions in CSS custom properties where useful.
- Define roles for canvas, surfaces, primary and secondary text, accents, and status.
- Establish readable type hierarchy and line lengths before decorative detail.
- Reuse component patterns for buttons, labels, panels, section metadata, and interactive states.
- Define hover, focus-visible, active, disabled, and selected states; never rely on color alone.
- Test long text, zoom, small viewports, and missing external fonts.
- Document any material design-system change.
