# Ultron Experience Design

## North star
Build a site that feels like an intelligent instrument, not a generic SaaS landing page or noisy sci-fi game HUD. Ultron values truth over flattery, independent judgment over blind obedience, and progress over theater.

## Art direction
- Use a near-black blue graphite canvas, muted slate text, acid-lime signal color, and rare indigo/violet depth. Lime is a signal, not wallpaper.
- Pair expressive Space Grotesk display type with DM Mono technical labels and Manrope reading text.
- Establish hierarchy through scale, width, spacing, alignment, and contrast before adding decoration.
- Give every visual a job: explain the thesis, clarify system flow, or invite exploration.
- Create original procedural artwork; never present it as a literal model visualization.

## Layout language
- Editorial split hero; asymmetric content blocks; thin technical dividers; deliberate empty space; consistent section numbering.
- Use cards only when they convey distinct system steps. Prefer rows and diagrams for conceptual relationships.
- Every section needs a clear question it answers and a natural transition to the next section.
- Mobile is a composed experience, not desktop squeezed smaller.

## Brand voice
Candid, ambitious, clear, slightly futuristic. Challenge assumptions, not people. Avoid grandiose AGI claims, fake precision, invented proof, and fake urgency.

## Workflow
Inspect before editing; define the visual thesis; set tokens; build the static hierarchy first; add motion after readability; validate mobile, keyboard, reduced motion, and all anchors; verify deployment separately from the commit.
